Vacancy_project Программа для поиска вакансий на [hh.ru](https://hh.ru), фильтрации по ключевым словам, сортировки по зарплате и сохранения результатов в JSON-файл.

---

## Возможности

- Поиск вакансий по ключевому слову.
- Получение топ-N вакансий по зарплате.
- Фильтрация по ключевым словам в описании.
- Расчёт средней зарплаты.
- Сохранение результатов в файл `vacancies.json`, исключая дубликаты.
- Чтение и удаление сохранённых вакансий.

## Пример использования

```
Введите поисковый запрос для поиска вакансий: python
Сколько вакансий с наивысшей зарплатой вы хотите увидеть? 3
Введите ключевое слово для фильтрации по описанию: разработка

Топ-3 вакансий по зарплате:
Название: Senior Python Developer
...

Средняя зарплата по найденным вакансиям: 120000 руб.
Хотите сохранить найденные вакансии в файл? (да/нет): да
Вакансии сохранены в файл.
```

## Тестирование

Проект покрыт тестами, включая:
- проверку уникальности вакансий при сохранении,
- чтение и удаление из файла,
- фильтрацию по ключевым словам,
- сортировку по зарплате.
